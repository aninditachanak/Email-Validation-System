# Email Validation System

A simple **Email Validation System** developed using **Python**. This mini project checks whether an email address is valid or invalid using **string methods, conditional statements, and user-defined functions**.

## Features

* Takes email address as user input
* Checks basic email format
* Validates the presence of `@`
* Checks for a valid domain
* Uses Python string methods
* Uses user-defined functions
* Simple and beginner-friendly project

## Technologies Used

* **Python**
* String Methods
* User-Defined Functions
* Conditional Statements

## How It Works

The program takes an email address from the user and checks some basic conditions:

1. The email should contain `@`.
2. The email should contain a valid domain.
3. The email should not contain unnecessary spaces.
4. The email should have text before and after `@`.
5. The program displays whether the email is **Valid** or **Invalid**.

## Example

```text
Enter your email: anindita@gmail.com

Email is Valid
```

Another example:

```text
Enter your email: anindita@gmail

Email is Invalid
```

## How to Run

Make sure Python is installed on your computer.

```bash
python email_validation.py
```
